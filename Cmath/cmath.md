# Cmath

1. sqrt(x) : 
  - returns the square root of x in double

2. pow(a,b) : 
  - return a to the power b in double

3. abs(x) / fabs(x) : 
  - returns absolute value of x
  - llabs for long long
  - fabs(x) for double

4. floor(x) , ceil(x) , round(x) :
  - returns in double

5. log(x) , log2(x) , log10(x) : 
  - log(x) based on napier's constant
  - log2(x) is useful to know how many bits
  - log10(x) helps use to find the number of digits in a number

6. hypot(x,y) :
  - returns sqrt(x² + y²)
